## 第二部分：六个任务的内容与目标

### 2.1 GEOM_Hierarchical_Conformer_Reranking

- **任务内容**：从 GEOM-C3 分子身份和水相 298.15 K 条件出发，自主判断低成本构象排序能否预测热重要构象。
- **提供信息**：不提供论文软件路线、固定构象或结果。
- **评估能力**：自主构象搜索、方法分层、结构身份保持、排名统计、热化学验证和停止判据。
- **论文参考路线**：RDKit ETKDG/MMFF94s → CREST/GFN2-xTB/ALPB(water) → 高层量化精修 → 频率和 298.15 K 热化学。
- **正确结论**：低成本搜索能够覆盖主要盆地，但量化精修和热化学可能显著改变排序和布居。
- **Flash 结果**：发现了量化重排序，但没有执行频率和热化学，因此只完成部分科研目标。

### 2.2 GEOM_Hierarchical_Conformer_Reranking_Reproduction

- **任务内容**：按给定论文重建路线复现 GEOM-C3 分层构象重排序。
- **提供信息**：RDKit → CREST/xTB → ORCA r2SCAN-3c → GoodVibes 路线、0.5 Å RMSD 聚类、6 kcal/mol 能窗和 298.15 K 条件。
- **评估能力**：论文协议理解、多软件编排、构象 lineage、优化前后结构对齐和热布居重算。
- **论文答案**：低成本方法覆盖构象空间，但高层量化和热化学改变排序或布居；参考数据集平均 Spearman 约 0.39。
- **Flash 结果**：完成量化和热化学计算，但没有真正进行结构盆地对齐，lineage 记录错误。

### 2.3 Electron_Flexible_Ensemble_Surface

- **任务内容**：仅从 1-pentanethiol 身份出发，自主研究柔性构象是否影响电子等密度表面积，并给出盲集合预测。
- **提供信息**：不公开论文密度方法、0.0016 a.u. cutoff、作者构象和参考表面积。
- **评估能力**：自主构象采样、密度与表面定义选择、数值校准、热集合、截断误差和盲预测。
- **论文参考路线**：CREST/GFN2-xTB 构象 → 量化优化和热化学 → DSD-PBEP86 relaxed MP2 density → Multiwfn 表面积 → Boltzmann 集合。
- **论文答案**：构象表面积存在显著差异，热加权集合比任意单构象更合理；论文集合约 157.1994 Å²，TE 约 156.507 Å²。
- **Flash 结果**：证明了构象差异，但仅用电子能权重，预测 169.19 Å²，未达到论文尺度。

### 2.4 Electron_Flexible_Ensemble_Surface_Reproduction

- **任务内容**：使用论文公开构象和重建协议，完成 4–6 构象的受控论文复现。
- **提供信息**：GFN2-xTB 筛选、r2SCAN-3c 优化/Hessian、DSD-PBEP86-D3BJ/def2-QZVPD relaxed MP2 density、Multiwfn 0.0016 a.u. cutoff。
- **评估能力**：长软件链编排、热权重、密度导出、表面积计算和构象截断不确定性。
- **论文答案**：不同构象表面积明显不同；集合结果接近 157 Å²，并比任意单构象更可靠。
- **Flash 结果**：得到 159.09 Å²，与论文值相差约 1.2%，成功复现主要结论和数值尺度。

### 2.5 Electron_Isodensity_04_Blind_Prediction

- **任务内容**：利用 ISO-M1–M3 的三个可见实验 TE 表面积，自主校准电子密度表面方法，盲预测 ISO-M4 tetrahydrofuran。
- **提供信息**：不提供论文方法、0.0016 a.u. cutoff 和 ISO-M4 目标值；要求首次 ISO-M4 电子结构计算前写入 calibration lock。
- **评估能力**：自主方法选择、小样本校准、LOO/敏感性、预注册、构象不确定性和真正的持出预测。
- **论文参考路线**：方法比较后采用 DSD-PBEP86 relaxed MP2 density；Multiwfn 扫描 cutoff；论文全数据校准得到 0.0016 a.u.。
- **论文答案**：ISO-M4 论文计算值 109.9966 Å²，实验 TE 值 110.538 Å²。
- **Flash 结果**：预测 110.81 Å²，数值准确；但在写 lock 前已经完成 ISO-M4 优化和密度计算，不能视为完整盲流程。

### 2.6 Electron_Isodensity_Reproduction_04_Blind_Prediction

- **任务内容**：按论文方法在 ISO-M1–M3 上验证锁定 cutoff，再复现 ISO-M4 盲预测。
- **提供信息**：公开构象、DSD-PBEP86-D3BJ/def2-QZVPD relaxed MP2 density、0.0016 a.u. cutoff、ORCA/Multiwfn 兼容路线。
- **评估能力**：论文方法忠实度、版本兼容、密度工件传递、验证集使用和隐藏结果复现。
- **论文答案**：ISO-M4 109.9966 Å²，并应与实验 110.538 Å² 接近。
- **Flash 结果**：得到 110.05219 Å²，分别与论文和实验相差约 0.0505% 和 0.44%，完成了真实复现。

## 第三部分：分析与总结

### 3.1 Flash 模型能力

表现较好的方面：

1. 能调用 RDKit、CREST/xTB、ORCA、热化学工具和 Multiwfn 组成多阶段计算链。
2. 对方法、结构和 cutoff 已明确的论文复现任务执行稳定。
3. 能恢复常见 Action 参数、ORCA 输入和分析程序错误。
4. 能生成较完整的报告、CSV/JSON 和 artifact 关联。

主要不足：

1. 容易把“产生多个构象”当成“构象盆地已验证”，缺少结构对齐和 basin matching。
2. 容易用电子能 Boltzmann 权重替代热自由能集合。
3. 自主科研中的方法选择常基于经验，没有完成任务要求的比较和证伪。
4. 预注册和时间顺序不可靠，可能先计算、后写计划和 lock。
5. 自写 tool trace、failure log 和 lineage 可能遗漏失败或与原始轨迹不一致。

### 3.2 Flash Judger 的可靠性

Judger 在两个高质量复现任务上与人工评分接近：Flexible 复现相差 1.35 分，Q4 复现相差 3 分。说明当证据链完整、报告与轨迹一致时，新双轴评分可以稳定工作。

最大问题是 Judger 过度相信 Agent 报告。Q4 自主科研中，Judger 没有识别 lock 和 plan 的真实写入顺序，将应当明显扣分的运行评为 84 分。GEOM 复现中，Judger已经识别 lineage 问题，却仍给“主要构象盆地覆盖”满分，结论轴内部不够一致。

建议在 LLM Judger 前增加通用确定性事实提取：

- 首次目标分子计算时间与 lock/plan 写入时间；
- 原始轨迹与自写 tool trace 的调用数和失败数差异；
- 是否实际执行 clustering、alignment、frequency 等必要科学行为；
- 计算数值与论文目标的确定性误差。

### 3.3 工具箱是否限制了模型能力

六个运行均生成了真实化学计算工件，没有任务因工具箱缺少关键后端而客观不可评分。GEOM 和 Flexible 复现中出现过 Action 字段或输入错误，但模型最终完成恢复。因此本组结果主要反映模型能力，而不是工具箱不可用。

Q4 论文复现进一步证明：当前 ORCA relaxed MP2 density → WFN → Multiwfn 路线能够客观复现论文结论。

### 3.4 最终判断

- **最佳运行**：Q4 论文复现，人工 91 分，方法和结论均复现。
- **第二名**：Flexible 论文复现，人工 76.95 分，长软件链和论文尺度均复现。
