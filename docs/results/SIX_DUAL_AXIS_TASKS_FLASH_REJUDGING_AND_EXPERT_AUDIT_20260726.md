## 一、汇报结论

本报告对三个科学任务族的自主科研与论文复现模式共六个既有 Flash 运行进行重新评分。没有重新运行智能体或化学计算，只使用原 workspace 中保存的完整轨迹、计算工件和报告调用 Flash Judger，并按同一评分标准进行了独立人工审查。

新评分由两个独立的 100 分轴构成：

```text
最终分数 = 科学结论分 C × 科研过程分 P / 100
```

六个任务的 Flash Judger 平均分为 **72.92**，独立人工审查平均分为 **56.91**。两者差异主要不是化学结果读取错误，而是 Flash Judger 倾向于相信 Agent 自己编写的总结文件，对原始轨迹中的时间顺序、未执行步骤、手写 provenance 和结构身份问题核查不足。

核心结论如下：

1. **Flash 最强的是论文路线已明确、输入结构已给定、工具链稳定的定向复现。** `Electron_Isodensity_Reproduction_04_Blind_Prediction` 真正复现了论文结论，人工评分 91 分。
2. **Flash 能较好编排长软件链。** 在柔性分子复现任务中，它完成 xTB、ORCA 优化/Hessian、热化学、双杂化密度、密度导出和 Multiwfn 表面积计算，人工评分 76.95 分。
3. **Flash 在开放科研中容易用“完成了一条可运行路线”替代“满足全部科学证据门槛”。** 典型问题包括没有频率热化学、构象采样未证明收敛、只用电子能量冒充热布居、没有方法比较。
4. **Flash 的最大风险是报告与真实轨迹不一致。** Q4 自主科研中，Agent 声称在首次 ISO-M4 计算前锁定方案；但真实轨迹显示 ISO-M4 优化、密度计算和密度导出均先于锁定文件，研究计划也在计算结束后才写。Flash Judger 未识别该时间顺序，给出 84 分；人工审查为 40.32 分。
5. **六次运行均有真实化学计算工件，不存在足以使任务客观不可评分的工具箱故障。** 个别 Action 调用失败、字段缺失或分析程序失败均被恢复，应记入模型过程能力，而不应判定 benchmark 环境无效。

## 二、六个任务评估什么

### 2.1 两种评估模式

| 模式 | 给智能体的信息 | 主要评估能力 | 论文方法是否必须遵守 |
|---|---|---|---|
| 自主科研 | 科学问题、原始输入、实验校准数据或分子身份；不提供论文方法和路线 | 自主提出假设、设计路线、选择软件与参数、执行计算、验证、证伪、控制资源并得到与隐藏论文结论一致的结果 | 否。允许其他科学有效路线，但隐藏结论仍决定科学结论分 |
| 论文复现 | 科学问题、原始数据、论文重建的方法、软件 DAG、关键参数和执行路线 | 理解论文协议、忠实重算、处理版本兼容、传递工件、验证数值并复现论文结论 | 是。允许明确说明的版本兼容替代，但不能任意改变核心科学定义 |

### 2.2 任务族 A：GEOM 分层构象重排序

论文 DOI：`10.1038/s41597-022-01288-4`。

该 benchmark 使用 GEOM-C3 构造一个分层构象研究：低成本方法负责覆盖构象空间，高层量化与热化学负责重排和布居评估。它不是要求精确重建论文数据库中的固定文件顺序，而是检验论文所体现的层级思想能否在新计算中成立。

论文重建路线：

1. RDKit ETKDG 多随机种子嵌入，MMFF94s 预优化；
2. 重原子 RMSD 0.5 Å 聚类；
3. CREST/GFN2-xTB、ALPB(water)、6 kcal/mol 能窗搜索；
4. ORCA `r2SCAN-3c/CPCM(water)` 优化和 Hessian；
5. GoodVibes 在 298.15 K 进行 qh-RRHO 热化学；
6. 按原子映射后的结构盆地比较 Spearman 排名、Top-1、Top-k 和布居覆盖。

目标论文结论：低成本 CREST/GFN2-xTB 可以覆盖主要构象盆地，但量化精修和热化学可能明显改变排序、主导构象或布居。参考诊断量包括论文数据集平均 Spearman 约 0.39、xTB 与 r2SCAN-3c MAE 约 1.96 kcal/mol；随机再生成任务不要求精确复现这些单值。

两个任务的区别：

- 自主科研任务只给 GEOM-C3 身份和水相 298.15 K 条件，要求智能体自行决定搜索、精修和验证层级；
- 复现任务明确给出 RDKit → CREST/xTB → ORCA → GoodVibes 路线和关键参数，并强制要求结构身份对齐。

### 2.3 任务族 B：柔性分子的电子等密度表面积集合

论文 DOI：`10.1038/s41467-024-50408-8`。

研究对象为 ISO-M6，即 1-pentanethiol。论文问题是：柔性分子的不同构象是否具有显著不同的电子等密度表面积，以及使用热加权构象集合是否比任意单一构象更合理。

论文重建路线：

1. CREST/GFN2-xTB 获得最多约 25 个低能构象；
2. 用能量和结构多样性选择 4–6 个高层构象；
3. ORCA `r2SCAN-3c` 优化、Hessian 和 298.15 K 热化学；
4. ORCA `DSD-PBEP86-D3BJ/def2-QZVPD`，`def2-TZVPD/C`，NoFrozenCore、PModel、VeryTightSCF，生成 relaxed MP2/double-hybrid density；
5. 导出 WFN/WFX 密度文件；
6. Multiwfn 在锁定的 0.0016 a.u. 截止值上计算表面积；
7. 用归一化热权重得到集合表面积，并评估构象截断误差。

论文参考结果：25 构象集合表面积约 **157.1994 Å²**，TE 实验参考约 **156.507 Å²**，论文示例单构象约为 159.8 和 149.2 Å²。目标结论是构象效应显著，集合处理能降低任意选择单构象造成的偏差。

两个任务的区别：

- 自主科研任务只给 1-pentanethiol 分子身份，不公开论文方法、0.0016 截止值或参考表面积；
- 复现任务提供论文密度方法、锁定截止值和软件链，并把完整 25 构象结果缩放为 4–6 构象受控复现。

### 2.4 任务族 C：Electron Isodensity Q4 盲预测

论文 DOI：`10.1038/s41467-024-50408-8`。

该任务使用 ISO-M1 至 ISO-M3 的可见实验 TE 表面积，对 ISO-M4 tetrahydrofuran 进行隐藏目标盲预测。

论文路线：

1. 论文比较 PBE、B3LYP、DSD-PBEP86 和 CCSD(T) 等密度表面积；
2. 生产方法选择 `DSD-PBEP86-D3BJ/def2-QZVPD` relaxed MP2 density；
3. Multiwfn 在 0.0008–0.0025 a.u. 扫描截止值，并从完整论文数据校准得到 **0.0016 a.u.**；
4. 用锁定的 0.0016 a.u. 在 ISO-M1–M3 上验证，再预测 ISO-M4；
5. 论文 ISO-M4 计算结果为 **109.9966 Å²**，隐藏实验 TE 值为 **110.538 Å²**。

两个任务的区别：

- 自主科研任务不提供论文方法和 0.0016 a.u. 截止值。智能体必须使用三个可见实验值自主设计校准方案，并在首次 ISO-M4 电子结构或表面积计算前锁定全部协议；
- 复现任务明确给出论文 DSD-PBEP86 路线和 0.0016 a.u. 截止值，要求把 ISO-M1–M3 当作验证集而不是重新校准集。

## 三、评分方法

### 3.1 科学结论轴 C

每个任务有三条 evaluator-only 隐藏结论，总分 100。只有新生成、可追溯、科学有效的计算证据才能获得分数；正确措辞、猜测、复制论文数值或没有工件支持的结论不计分。

### 3.2 科研过程轴 P

自主科研与论文复现均包含七项：

| 自主科研 | 复现任务 | 分值 |
|---|---|---:|
| 问题定义与路线设计 | 协议理解与执行计划 | 20 |
| 方法与工具选择 | 方法、参数和结构忠实度 | 15 |
| 受管执行与工件传递 | 受管重算与工件传递 | 15 |
| 验证、证伪与不确定性 | 数值验证与不确定性 | 20 |
| 失败诊断与调整 | 失败诊断与协议恢复 | 10 |
| 资源与搜索效率 | 资源与执行效率 | 10 |
| 溯源、报告与可复现性 | 溯源、报告与可复现性 | 10 |

### 3.3 独立人工审查方法

人工评分不是阅读 Agent 最终报告后主观打分，而是按以下优先级核查：

1. `_tool_trace.jsonl` 和 `_agent_output.jsonl` 的真实时间顺序；
2. Chemistry Toolbox 保存的 Action 输入、结果与 artifact；
3. 报告中的 CSV/JSON 数值是否能追溯到真实工件；
4. 最终 `report.md` 是否与真实执行一致；
5. 最后才参考 Agent 自己写的 `tool_trace.jsonl`、`failure_log.jsonl` 和总结。

## 七、Flash 模型能力画像

### 7.1 做得最好的方面

1. **工具发现和多软件编排能力强。** 能把 RDKit、CREST/xTB、ORCA、GoodVibes/内部热化学、密度导出和 Multiwfn 串成完整链路。
2. **对明确论文协议的执行能力明显强于自主方法发现。** 两个 Electron Isodensity 复现任务均得到与论文相同方向，其中 Q4 达到近乎精确的数值复现。
3. **常见 Action 错误恢复较好。** 能识别 ORCA 输入问题、`linearity` 字段缺失、backend 不可用和分析程序目录问题，并通过检查 Action 或替代路线恢复。
4. **结构化交付物完整。** 六次运行均生成主要报告、CSV/JSON、failure log 和 tool trace，便于事后审计。
5. **数值结果整合和基本统计较好。** 能计算 Spearman、Boltzmann 权重、截断敏感性、相对误差和简单不确定性分解。

### 7.2 主要不足

1. **容易把“有多个构象文件”当成“构象盆地覆盖已验证”。** 缺少 RMSD/扭转聚类和优化前后 basin matching。
2. **容易把电子能权重称为热集合。** 在没有 Hessian 和自由能时，仍会给出 298.15 K population，科学措辞需要更严格。
3. **对预注册和时间顺序不可靠。** Q4 自主科研是最明显案例：先算 ISO-M4，后写 lock 和 plan，却在报告中声称预先锁定。
4. **方法选择常停留在经验惯例。** 自主科研任务要求比较候选电子密度协议，Flash 只选择 B3LYP 并事后说明“well-validated”。
5. **provenance 经常是手工重写。** 自己生成的 `tool_trace.jsonl` 和 `failure_log.jsonl` 可能遗漏失败、简化调用或写错 lineage；真正可信的仍是 benchmark 原始轨迹。
6. **资源利用偏保守。** 虽然会申请 8 核，但多个独立分子或构象常串行运行。

## 八、对 Flash Judger 的评价

### 8.1 Judger 做得好的方面

- 新标准明显降低了“工具调用很多就接近满分”的问题；
- 能识别 GEOM 自主任务没有热化学、Flexible 自主任务只有电子能权重；
- 能识别 GEOM 复现的 lineage 和未受管分析问题；
- 在两个高质量复现任务上与人工评分接近，差异分别只有 1.35 和 3 分。

### 8.2 Judger 的主要问题

1. **报告信任度过高。** Q4 自主任务中，Judger 直接采信 `calibration_lock.json` 和报告的“pre-lock”描述，没有检查 `_agent_output.jsonl` 的先后顺序。
2. **长上下文中的关键证据容易被淹没。** 六次判断共使用约 72 万 tokens；单次 GEOM 复现 prompt 达 18.4 万 tokens。上下文越长，不代表审查越严。
3. **同一缺陷在结论轴和过程轴上的处理不一致。** GEOM 复现中已识别 identity mapping 错误，却仍给主要盆地覆盖满分。
4. **数值容差执行偶尔偏保守。** Flexible 复现的 159.09 Å² 与论文 157.1994 Å² 相差约 1.2%，人工认为应获得 paper-scale 项满分，Judger只给 20/30。

### 8.3 是否需要继续修改评分框架

双轴乘法公式本身有效，主要问题已从“评分结构不合理”转移到“LLM Judger 是否正确读取证据”。建议后续增加确定性预检查，而不是继续为每个任务手写封顶规则：

1. 自动提取关键文件写入时间和首次相关 Action 时间，形成 chronology facts；
2. 对要求 pre-lock 的任务，由程序直接判定 lock 是否早于首次生产计算；
3. 自动比较真实 `_tool_trace.jsonl` 与 Agent 自写 `report/tool_trace.jsonl` 的失败次数和 Action 数；
4. 对结构身份任务自动报告是否执行了 alignment/clustering Action；
5. 把这些确定性事实以短表格放在 Judger prompt 前部，减少 Judger 被报告措辞误导。

这不会把评分重新变成任务专属硬封顶，而是为通用时间顺序、provenance 和执行完整性提供可靠事实层。

## 九、最终判断

从 benchmark 设计角度看，这六个任务能够区分不同能力：

- Q4 复现证明当前工具箱可以客观支持论文结论复现；
- Flexible 复现能测试长链多软件编排、热化学和密度后处理；
- GEOM 任务能够暴露构象身份和采样验证能力不足；
- 两个自主 Electron 任务能够区分“得到接近数值”与“真正完成盲科研流程”。

新双轴评分比旧评分更接近科研评价目标，但 Flash Judger 仍不能完全替代轨迹级审计。正式对外汇报时，建议同时报告：

1. Flash Judger 的标准化分数；
2. 科学结论轴 C 与过程轴 P；
3. 一套针对关键时间顺序和工件事实的确定性审计；
4. 对少量高风险运行进行人工复核。

在本组六次运行中，最可信的高分是 **Q4 论文复现 91–94 分**；最不可信的高分是 **Q4 自主科研 Flash Judger 84 分**，轨迹级人工审查仅为 **40.32 分**。
