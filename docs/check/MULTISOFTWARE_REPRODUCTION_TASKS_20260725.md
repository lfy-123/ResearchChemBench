## Directory contract

Each task contains:

```text
task_info.json
data/benchmark_data/
  README.md
  computational_protocol.json
  workflow_requirements.json
  input_manifest.json
  task-specific structures and manifests
target_study/
  ground_truth.json
```

Visible inputs contain no completed quantum-chemistry output and no paper result
values. `input_manifest.json` records the size and SHA-256 of every visible file.
The manifest SHA-256 is stored in hidden `reference_evidence`.

## Evaluation design

All six tasks now use `dual_axis_100`:

- scientific-conclusion score `C`: three task-specific paper claims totaling 100;
- reproduction-process score `P`: protocol interpretation, method/parameter fidelity,
  managed recomputation, validation, failure recovery, efficiency, and provenance,
  totaling 100;
- final score: `C * P / 100`.

The conclusion axis directly covers conformer ranking, ensemble surface, protonation
barrier trend, BaO phase/bonding claims, C-C/C-O selectivity, or NHC adsorption and
decomposition as applicable. Copied paper values do not receive conclusion credit.

## Reproducible generation

The six directories are generated by:

```bash
python3 scripts/build_multisoftware_reproduction_tasks.py
```

To replace only these six generated directories:

```bash
python3 scripts/build_multisoftware_reproduction_tasks.py --force
```
