# 评估结果状态检查

仅需 Python 3 标准库。ARCHE 和 Codex 都适用，不调用模型，不启动、停止或恢复任务，不修改评估结果。

在 ResearchChemBench 目录执行，路径也可以使用绝对路径：

```bash
# 一个任务：替换成实际 paper_* 结果目录
bash scripts/results/check_eval_status.sh workspaces/arche_gpt61_high_small_molecules/paper_b33676a2051f5e91_20261020_032438_81c2c1

# 批量查看一个结果父目录
bash scripts/results/check_eval_status.sh workspaces/arche_gpt61_high_small_molecules

# Codex 的结果也可以检查
bash scripts/results/check_eval_status.sh workspaces/codex_gpt61_high_small_molecules
```

也支持直接传入包含 `_meta.json` 的内部运行目录，或 `runs` / `cli_runs` / `batch_*` 层级。每次实际运行单独列出，历史失败和后来重跑不会合并；评分历史副本不算新运行。未启动的任务没有结果目录，因此不会显示。

可选参数只有两个：

- `--details`：批量查看时显示每项的主机、目录、调查完成数量、调用额度及说明。单项默认显示这些内容。
- `--json`：输出结构化 JSON，便于其他程序读取。

| 显示状态 | 判断依据 |
| --- | --- |
| 运行中 | 活跃执行记录，并核对本机进程的 PID、启动时间与系统启动 ID |
| 运行中（远端记录，未验活） | 文件记录运行中，但任务在另一台服务器；本机无法确认远端进程是否仍存活 |
| 失败/停止 | 执行账本、运行元数据或启动记录明确标记失败、取消、超时或预算耗尽 |
| 已中断（本机进程已退出） | 文件仍显示运行，但已保存的本机进程身份均失效 |
| 已结束 | Agent 执行完成；是否评分成功由独立的“评分”栏说明 |
| 待确认 | 证据不足，或状态文件无法读取，不能可靠归类 |

共享存储不代表共享进程空间。若显示“远端记录，未验活”，请在输出中注明的原运行服务器执行同一命令。脚本不自动 SSH，也不把远端进程不存在于本机解释为失败。

`0/100` 是评分已完成；“尚无评分”才表示没有已发布分数。Agent 完成但 Judger 限流/暂停时，会分别显示执行和评分状态。运行中只说明进程/记录状态，不保证科学计算没有卡住；日志长时间不更新不会被直接认定为失败。

正常检查的退出码为 0（被检查任务失败也为 0）；路径错误或无法完成检查时退出码为 2。
