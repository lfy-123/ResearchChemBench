# Previous and Intermediate Results

This directory contains all workspace content that is not part of the 14 formal runs listed in
`workspaces/first_version_results/README.md`.

It includes earlier trials, failed or timed-out batches, dry runs, smoke tests, manual reproduction
validation, recovery calculations, submission metadata, and other intermediate artifacts. No data
was deleted during the reorganization.

The original top-level directory names are preserved below this directory so their provenance can
still be identified.
