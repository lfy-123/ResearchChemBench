# Legacy shared archive

`autonomous_inputs.zip` is retained only for historical build provenance and
paper-reported measurement recovery. Its coordinate seeds were derived by
perturbing author-optimized geometries and must not be mounted, linked, or used
as Agent-visible input for the six Heterobiaryl P(V) benchmark tasks.

The canonical task inputs are the normal files under each task's
`data/benchmark_data/` directory, generated by
`scripts/organize_heterobiaryl_task_inputs.py`.
