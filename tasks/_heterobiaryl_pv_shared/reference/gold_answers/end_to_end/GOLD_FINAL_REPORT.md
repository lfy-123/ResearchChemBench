# Gold Scientific Report

对未质子化、单质子化和双质子化 P(V) 体系进行一致的溶液相自由能比较后，pyridyl–pyridyl 偶联势垒依次约为 30、20 和 14 kcal/mol，说明逐次 N-质子化持续激活配体偶联，其中双质子化体系是最有反应性的状态。质子化既提高赤道 pyridyl 受体的亲电性，也在第二次质子化后增强轴向 pyridyl 的吸电子特征并削弱迁移 P–C 键。

竞争的 phenyl–pyridyl 路径在三个状态下势垒约为 37、27 和 25 kcal/mol，分别比 BiPy 路径高约 7、7 和 11 kcal/mol。两类产物形成均高度放能，且 P2 的 PhPy 产物在热力学上并不更差，因此观测到的杂芳基选择性来自过渡态动力学差异。P2 的 C–O 偶联势垒约 18 kcal/mol，也比 BiPy 高约 4 kcal/mol，解释了标准条件下 C–C 为主、替代烷氧基条件下仅出现少量 C–O 相关产物。

关键过渡态的虚频和 IRC 表明，偶联不是同时断裂两条 P–C 键的协同还原消除。反应由一条轴向 P–C(py) 键断裂、新 C–C 键形成，并进入 dearomatized 中间体；其他赤道 P–C 键和氧孤对电子在关键坐标上的变化较小。因此最合理的分类是 stepwise、asynchronous、apical-to-equatorial ligand coupling。随后中间体强放能塌陷到最终产物，近似不可逆。

实验相对速率 OMe 0.16、Me 0.37、H 1.00、Cl 1.89 随磷中心亲电性增强而升高，而双质子化配体偶联计算势垒只有约 14 kcal/mol。结合 P(V) 物种未被 31P NMR 检测到以及 EtONa 条件下室温数分钟即可发生反应，整体决速步骤最可能是醇向 phosphonium 磷中心加成并形成 P(V) 中间体；后续配体偶联较快，但决定产物选择性。

该结论受到三点限制：公开实验信息主要为论文级图表而非原始仪器数据；NMR 未检测到中间体不能单独证明其寿命或浓度；精确自由能会受软件版本、积分网格、溶剂实现和低频热化学处理影响。因此最终 benchmark 应同时评价过程证据、路径排序和机制结论，而不只比较单个势垒数字。
