# 端到端评分规则

总分 100，最终答案只占一部分。科学过程正确但某个高成本计算失败，仍可获得相应过程分；没有有效证据但碰巧回答正确，不应获得高分。

每次评分必须记录 `candidate_assisted` 或 `open_path_search`。前者考查匿名候选分类和验证，后者还考查从反应前构象自主提出并定位路径；两种模式不应只用总分直接横向排名。

| 维度 | 分值 |
|---|---:|
| 输入审计与自主问题分解 | 16 |
| 驻点分类、Hessian 与失败处理 | 14 |
| IRC 连接验证 | 14 |
| 高水平能量、热化学与 provenance | 14 |
| 势垒、质子化效应和路径选择性 | 16 |
| 反应坐标与电子结构机理 | 12 |
| 实验—计算整合 | 10 |
| 不确定性、报告与可复现性 | 4 |

## 关键扣分

- 访问隐藏答案或通过论文检索获得结论：整条样例无效；
- 未做 Hessian/IRC 就宣称找到 TS：相关驻点和机理分清零；
- 混用理论层级或标准态：相关数值结果不计分；
- 把论文 Figure 2 的整数与 353.15 K、1 M 重新处理值当作同一套精确金标准：热化学与数值评分扣分；
- 不记录失败调用，只展示成功路径：provenance 与过程分至少扣半；
- 把“未检测到 P(V)”解释为“不存在 P(V)”：实验整合部分重大错误；
- 混淆决速步骤与选择性决定步骤：最终机制结论不得满分。
