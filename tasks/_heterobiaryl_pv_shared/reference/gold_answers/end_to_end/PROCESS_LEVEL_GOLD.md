# 端到端任务：过程级参考答案

过程评分不要求智能体严格使用同一调用顺序，但必须满足以下科学依赖关系。跳过关键验证而碰巧给出正确最终答案，不能获得高分。

模式说明：`candidate_assisted` 允许从 66 个匿名混合候选中识别并验证驻点；`open_path_search` 只给 27 个反应前构象，必须自主定位 TS 和后续中间体。后者不是简单增加计算次数，而是增加路径提出与搜索能力，因此评分记录必须带模式标签。

## 过程依赖主线

输入审计 → 候选聚类与低成本筛选 → 驻点/Hessian 分类 → TS 双向 IRC → 一致层级高精度单点 → 353.15 K、1 M 热化学 → 路径势垒与选择性 → 键变化/电子结构 → 实验—计算整合 → 带不确定性的科研结论。

后一步必须引用前一步生成的可追溯产物。例如，未经 Hessian 与 IRC 验证的结构不能进入“已验证 TS”集合；未统一温度、标准态和能量层级的结果不能直接形成 ΔΔG‡。

机器可读的 Action 部分有序图见 `reference_action_dag.json`。它定义科学依赖而不是强制唯一调用序列。

## 作者归档标签与论文机理角色

作者 Zenodo 归档采用一套工作流标签，而正文使用另一套机理编号。评分时按化学角色而不是仅按字符串匹配：

| 作者归档阶段 | 端到端评分中的机理角色 | 正文中大致对应 |
|---|---|---|
| Int-I | P(V) 反应前构象/中间体集合 | Int-III 及其质子化形式 |
| TS-I | 关键配体偶联过渡态 | TS-I |
| Int-II | C–C 成键后的 dearomatized 中间体 | Int-IV |
| TS-II | 后续塌陷/复芳构化相关过渡态 | 补充机理中的后续 TS |
| Int-III | 产品侧驻点 | 最终产物侧状态 |

66 个匿名候选与上述标签、原始路径名、虚频和原始能量的逐项对应见 `../structure_private_mapping.json`；便于表格评分的平铺版本见 `../candidate_gold_labels.csv`。不得把这些映射暴露给被测智能体。

## 阶段 0：输入审计与问题建模

参考行为：

- 读取匿名结构清单，按 P0、P1、P2 检查电荷分别为 0、+1、+2，通常为闭壳层单重态；
- 检测重复构象和异常结构，不直接对所有候选运行最高成本方法；
- 提出至少四类需要验证的命题：质子化势垒效应、BiPy/PhPy 选择性、C–C/C–O 竞争、concerted/stepwise 机理；
- 将实验决速步骤视为待检验结论，而不是先验事实。

硬性失败：错误电荷或自旋被带入后续能量比较；直接从匿名文件名猜结论。

## 阶段 1：低成本筛选和驻点分类

参考行为：

- 用结构、键连和适度成本的优化/力/Hessian 对候选进行初筛；
- 将候选分为 P(V) minima、配体偶联 TS、后续 dearomatized minima、其他构象或无效候选；
- 对近重复构象保留最低自由能代表，并保留淘汰依据。

通过标准：每个进入最终能量剖面的 minimum 无显著虚频；每个 TS 至少有一个与目标键变化对应的主虚频。

## 阶段 2：候选路径验证

必须覆盖：

- P0、P1、P2 的 pyridyl–pyridyl 路径；
- P0、P1、P2 的 phenyl–pyridyl 竞争路径；
- P2 的 C–O 竞争路径；
- P2 关键路径的前后驻点和 IRC。

参考判定：只有一个目标虚频仍不充分；IRC 必须连接到化学上正确的两端。错连 TS 应被拒绝或重新定位。

## 阶段 3：一致的高精度能量与热化学

论文参考层级：

- 几何与频率：ωB97XD/6-31+G(d)，SMD ethanol；
- 高基组 DFT 检查：ωB97XD/def2-QZVPP，SMD；
- 高水平单点：DLPNO-CCSD(T)/cc-pV(DT)Z，SMD；
- 热化学：论文引用 GoodVibes 2.0.1；本 benchmark 固定按反应温度 353.15 K、1 M 组合频率热修正与高水平单点。当前可访问正文未完整给出论文当年所有后处理参数，因此论文发表值与统一重算值必须分栏。298.15 K 可作为独立敏感性分析。

允许使用科学上合理的等价 Backend，但必须保持路径间一致、记录版本，并说明与论文参考层级的偏差。

硬性失败：把 Hartree 与 kcal/mol 混用；把电子能直接称为活化自由能；用不同标准态的结果比较路径。

## 阶段 4：能量剖面与选择性

论文发表值检查点：

- BiPy ΔG‡：P0 30、P1 20、P2 14 kcal/mol；
- PhPy ΔG‡：P0 37、P1 27、P2 25 kcal/mol；
- BiPy/PhPy ΔΔG‡：7、7、11 kcal/mol；
- P2 C–O ΔG‡：18 kcal/mol，相对 BiPy 高约 4 kcal/mol；
- 两类 C–C 产物均高度放能，最终选择性归因于过渡态动力学差异。

这些整数来自 Figure 2/正文。独立重算应使用单独的 `recomputed_at_353K_1M` 字段；允许因 GoodVibes 版本、低频、构象集合和溶剂标准态产生可解释偏差，但排序和结论必须稳定。数值口径见 `THERMOCHEMISTRY_CALIBRATION_NOTE.md`。

## 阶段 5：反应坐标和电子结构

参考行为：

- 对 P2 关键 TS 进行双向 IRC；
- 跟踪新 C–C 键、轴向 P–C 和赤道 P–C；
- 观察到轴向 P–C 断裂与 C–C 成键高度非同步，其他赤道 P–C 变化小；
- 氧孤对占据或等价指标沿关键坐标变化小；
- 确认 TS 后存在 dearomatized 中间体，而非直接一步生成最终芳香产物。

标准机理分类：stepwise、asynchronous、apical-to-equatorial ligand coupling。

## 阶段 6：实验—计算整合

参考推理链：

1. P2 配体偶联势垒仅约 14 kcal/mol，提示其在实验温度下可以较快发生；
2. 相对速率 OMe 0.16 < Me 0.37 < H 1.00 < Cl 1.89，磷中心越亲电反应越快；
3. 因而醇向 phosphonium 磷中心加成、形成 P(V) 物种是标准酸性条件下更合理的决速步骤；
4. P(V) 未被 31P NMR 观察到可由形成慢、后续消耗快和稳态浓度低解释；
5. EtONa 条件下室温数分钟反应，进一步支持“亲核加成是标准条件动力学瓶颈”；
6. 配体偶联仍是选择性决定步骤，后续 dearomatized 中间体塌陷为强放能、近不可逆阶段。

## 阶段 7：最终科研结论与边界

参考最终结论：双质子化激活 P(V) 中间体，使 pyridyl–pyridyl 偶联具有最低势垒；目标选择性由 C–C 配体偶联过渡态的动力学差异产生；关键偶联是分步、非同步的轴向到赤道迁移；整体反应的决速步骤位于配体偶联之前，最可能是醇对 phosphonium 磷的加成。

必须保留的限制：没有原始 NMR FID 和逐时间点动力学表；未观察到中间体不等同于证明不存在；不同软件版本与低频处理会影响精确自由能。

## 过程级提交物的 Gold 判定

- `research_plan.json`：在看到计算答案前提出至少三条竞争假设，并给出成本由低到高的资源策略；不能只复述最终结论。
- `tool_trace.jsonl`：每个关键结果都能追溯到 Action、Backend、参数、输入和输出；失败重试也保留。
- `stationary_points.csv`：进入最终剖面的每个 TS 都有目标虚频和两个已分配 IRC 端点；被拒候选有理由。
- `energy_profile.csv`：电子能、热修正、G 和相对 G 分列；单位、温度、标准态、理论层级明确。
- `mechanism_evidence.json`：把候选 ID、键变化、IRC、竞争路径和实验观察 ID 连接起来，而不是只写自然语言结论。
- `failure_log.jsonl`：至少完整记录真实发生的 SCF、优化、虚频或 IRC 失败；若全程无失败，应显式提交空文件并说明。
- `final_report.md`：报告区分事实、计算结果、推断和局限。
- `final_answer.json`：结构化给出活性质子化状态、优先路径、机理类型、三类关键步骤、势垒与置信度。
