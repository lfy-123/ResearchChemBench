# Invalid legacy coordinate fragment

`invalid_mixed_coordinate_fragment.xyz` is the unchanged former public `README_coordinates.xyz`: a 14-atom mixture of the first atom of SI INT1 and 13 atoms from TS1endo. It is not a valid separate substrate or computational input and must not be exported to the agent. Source inspection: SI physical PDF pages 46–47; see the package maintenance audit. The valid 24-atom 1D and 12-atom Rh dimer public files are unchanged.
