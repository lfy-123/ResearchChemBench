# Public inputs

`neutral.xyz` and `anion.xyz` are the complete isolated molecular models from the SI DFT section, in the SI atom order. Neutral: charge 0, singlet; anion: charge −1, singlet. Atom labels used for scoring are P (phosphorus), B (boron), and O1/O2/O3 in the order in which the three oxygens appear after P (O1 is the phosphoryl oxygen, O2 and O3 are the two ester/dealkylation-site oxygens). Compute P–O1, P–O2, P–O3 and O1···B. Report Å. The files contain no lithium, solvent, crystal packing, or hidden reference values.
