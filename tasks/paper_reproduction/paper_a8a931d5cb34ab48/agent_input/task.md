# Scientific objective

Determine the fundamental anharmonic O–H stretching frequency (cm⁻¹) and dimensionless oscillator strength for neutral TFE···benzene, TFE···toluene, TFE···o-xylene, TFE···m-xylene, and TFE···p-xylene complexes.  Test the authors' qualitative hypothesis that methyl substitution and its position can tune the O–H···π interaction and its vibrational signature, without assuming that hypothesis is correct.  The scored object is the fundamental O–H transition for each explicitly named complex, not an overtone, an isolated-monomer transition, or an equilibrium constant.

# Public inputs and scientific boundaries

Read `data/inputs/systems.json`.  It defines the unique monomer connectivity, names, neutral charge, singlet multiplicity, and five complex pairings.  Generate three-dimensional noncovalent structures independently.  The paper's qualitative route uses gauche TFE and an O–H donor directed toward the aromatic π face; use that as a testable starting hypothesis, while retaining and labeling any alternative conformers.  Do not covalently join monomers or change protonation, charge, multiplicity, or aromatic substitution pattern.  Report frequencies in cm⁻¹ and oscillator strengths as dimensionless values.  Experimental gas/matrix band positions may be used as contextual checks when their environment is identified.  Do not use the paper, SI, general web, or hidden evaluator files as inputs.

# Required scientific validation/investigation

For every retained complex, document how candidate geometries were generated, deduplicated, and advanced.  Optimize each advanced structure and provide evidence that it is a stationary minimum (or explicitly report a bounded failure and its cause); preserve a stable candidate ID and coordinates.  Compute the fundamental O–H anharmonic observable with a defensible method and state the coordinate/model, numerical convergence checks, and units.  Validate at least one result per complex by an independent check such as a second conformer, a repeat calculation, a method/model sensitivity test, or a comparison to an identified experimental environment.  The investigation is complete when each of the five named systems has either a validated result or a scientifically explained bounded failure, every retained candidate has provenance, and the report states search coverage and limitations.  Stop after the stated candidate-generation space has been sampled and additional candidates no longer change the selected interpretation, or stop earlier only with an explicit coverage limitation and failure status; never claim exhaustive global conformer discovery without evidence.

# Deliverables

Write `report/results.json` using the submission schema.  Include per-system candidate identity, coordinates or a reproducible structure reference, optimization/minimum evidence, frequency and oscillator strength when available, validation context, and status.  Include the comparison/trend conclusion, author-hypothesis assessment, search coverage, stopping condition, and limitations.  A bounded-failure branch is allowed only when the missing result and scientific reason are explicitly recorded.  Also include a concise human-readable report if useful, but the JSON is authoritative.
