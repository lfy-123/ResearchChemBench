# Scientific objective

Determine the neutral gas-phase equilibrium geometry of 4,4-difluoro-8-phenyl-4-bora-3a,4a-diaza-s-indacene (Ph-BODIPY, C15H11BF2N2) from the supplied indexed molecular identity. The authors proposed that an almost planar dipyrromethene core with a twisted phenyl substituent is an appropriate structural model; independently test that qualitative route. Report an optimized equilibrium structure and structural descriptors that test core planarity and phenyl twisting. The evaluator will compare the submitted non-hydrogen coordinates with a hidden experimental gas-phase reference. Do not assume that the qualitative route proves the result.

# Public inputs and scientific boundaries

The only molecular input is `data/inputs/ph_bodipy_connectivity.json`, an answer-neutral 31-atom composition/connectivity specification with fixed atom indices; it contains no Cartesian geometry. Construct a chemically sensible starting geometry or documented conformer set from this identity. The molecule is neutral, closed-shell, singlet Ph-BODIPY; model the isolated gas-phase molecule without solvent, crystal packing or counterions. You may generate conformers and choose computational methods, but must state software, method, basis/model, convergence, and any symmetry constraints. The experimental GED coordinates and all paper numerical results are hidden and must not be used as inputs. For aggregate distance statistics use only non-hydrogen pairs; report the complete pair manifest and how bonded pairs are defined if that subset is used. This task evaluates geometry and validation, not spectra, reaction energetics or condensed-phase properties.

# Required scientific validation/investigation

Independently construct and optimize the molecule or a documented set of deduplicated starting conformers. Preserve the public atom indices in every reported candidate. Establish that each candidate presented as a minimum passes an appropriate outcome-based check (for example, vibrational analysis with no imaginary modes, or a clearly justified alternative), and attach the criterion, outcome and diagnostics to that candidate. Report the phenyl–core twist as the acute-equivalent magnitude of dihedral 16-15-12-2: wrap the signed dihedral to [-180°,180°], then report `min(abs(d),180-abs(d))` in [0°,90°]. Report core planarity as the RMS perpendicular distance in Angstrom of atoms 1-12 from their least-squares best-fit plane. Provide all 190 pair distances for the 20 non-hydrogen atoms, identified by their public index pair and derived from the submitted coordinates, so the evaluator can perform a like-for-like hidden-reference comparison; do not claim MUE, MSE or RMSE against data you were not given. A complete investigation must include method/convergence provenance, candidate-specific minimum validation, mapping, and uncertainty or sensitivity discussion. Completion is reached when the selected structure passes the stated minimum check and all requested descriptors and pair distances are present. Stop after the documented conformer/method scope has been exhausted or, for a direct single-structure study, after one converged minimum plus an independently justified validation check; do not claim global coverage beyond the searches actually performed.

# Deliverables

Write `report/results.json` conforming to `submission_schema.json`. A complete branch includes method/provenance, candidate identities and candidate-specific validation, the selected candidate's 31 indexed coordinates, the two fixed descriptors, the 190 non-hydrogen pair distances, sensitivity/uncertainty, limitations and a conclusion. A bounded-failure branch is acceptable when no validated structure is obtained; it requires the attempted route, stage reached, diagnostics, work completed, limitations and a bounded conclusion, and does not require invented coordinates, descriptors or distances.
