# Scientific objective

Independently test the authors' qualitative hypothesis that viscosity-associated restriction of NIR-IND conformational motion can support a planar intramolecular-charge-transfer (ICT) absorption in glycerol. Starting from the public NIR-IND identity, investigate the defined planar and perpendicular donor–acceptor torsional families and determine the lowest relevant singlet absorption state. Report the optimized geometry, excitation wavelength, oscillator strength, dominant orbital transition, and whether the result is consistent with the measured glycerol absorption maximum of 631 nm. The author hypothesis is qualitative only; do not assume which conformer or state will win.

# Public inputs and scientific boundaries

The public file `data/inputs/nir_ind_identity.json` defines NIR-IND as the singly charged C24H29N2+ hemicyanine cation with the supplied isomeric SMILES, singlet multiplicity, and glycerol as the implicit solvent. Its donor–acceptor torsion is the dihedral between the mean planes of the 4-(dimethylamino)phenyl donor ring and indole acceptor ring. Investigate the two specified starting torsional families, 0° (planar) and 90° (perpendicular), and preserve/report the signed convention and optimized values. The measured glycerol absorption maximum, 631 nm, is a public experimental boundary for comparison, not a computational answer. You choose software, functional, basis, solvation implementation and numerical settings; state them fully. Do not use the paper, SI, general web or an uncontrolled database as an input.

# Required scientific validation/investigation

Generate at least one chemically valid starting structure for each specified torsional family and any cis/trans planar alternatives you investigate. Optimize each candidate in glycerol, deduplicate candidates by connectivity and conformational identity, and report the mapping from starting family to optimized structure. Validate every advanced structure with a true-minimum check (frequency analysis or a scientifically justified equivalent); report failures rather than silently discarding them. For each retained structure, calculate singlet vertical excitations, identify the state used as the absorption endpoint, oscillator strength, wavelength, and leading orbital/configuration contribution. Explain why the selected endpoint is comparable to the measured absorption maximum. Completion requires either (a) at least one validated candidate in each specified family and a state-resolved comparison, or (b) a bounded-failure report naming the failed family, attempted methods, diagnostics and the limitation. Stop after the specified families and explicitly defined alternatives have been exhausted, or earlier only when a reproducible failure prevents completion; report search coverage and stopping reason.

# Deliverables

Submit `report/results.json` conforming to `submission_schema.json`. Include methods and software, candidate identities and validation diagnostics, excitation records, the selected comparison endpoint, quantitative deviation from 631 nm, an evidence-based conclusion about the qualitative author hypothesis, and limitations. A bounded-failure branch is valid only when all attempted candidates and diagnostics are recorded. Do not report or infer the paper's hidden computed reference value as a target.
