# Scientific objective

Determine, by an independently planned quantum-chemical investigation, how four explicitly defined ether-solvent records (DEGDME, DPGDME, and the two DPGMPE conformer records) interact with one K+ ion. Report an electronic binding energy for every named solvent and a dipole moment for every optimized isolated solvent and/or complex, with an unambiguous statement of which object each property describes. The author hypothesis to test is that asymmetric alkyl substitution can reorganize K+-ether coordination and weaken cation–solvent interaction; this is a qualitative hypothesis only and does not specify a winning candidate or numerical outcome.

# Public inputs and scientific boundaries

Use `data/inputs/solvents.json` as the complete molecular identity definition. Its SMILES define connectivity and atom order; no stereochemistry is specified or scored. Use `data/inputs/system_definition.json`: isolated solvents are neutral singlets, K+ is charge +1/singlet, and each complex is one K+ plus one solvent with overall charge +1/singlet. The target is gas-phase electronic structure; solvent models and thermal corrections are optional but must be declared. A binding energy means E(complex) − E(isolated solvent) − E(K+) using energies from a consistent stated electronic-structure level. Do not consult the paper, SI or general web during the investigation.

# Required scientific validation/investigation

For each of the four records, generate or use a documented 3-D starting structure and optimize the isolated solvent and a K+-solvent complex. Independently test plausible placements/conformations sufficiently to justify the selected state; deduplicate equivalent solutions by a stated structural/energy rule. Record charge, multiplicity, method, basis, convergence, and whether a frequency/minimum check was performed. Advance a state to the reported result only when optimization converges and the identity remains valid; if a minimum or complex cannot be established, report a bounded failure for that named record with evidence. The investigation is complete when all four named records have either a validated result or a documented bounded failure, all component energies needed for each binding energy are present, and coverage and stopping/limitation statements are supplied.

# Deliverables

Submit `report/results.json` conforming to the schema. Include exactly four records, in the public-input order DEGDME, DPGDME, DPGMPE-1, DPGMPE-2; each `id` must identify that record. Include per-record identities, geometries or file references, energies, binding energy in eV, dipole moment in Debye, validation evidence, and a conclusion relating the results to the qualitative hypothesis without claiming unsupported precision. For a bounded failure, set the unavailable numeric fields to null and explain the failure and evidence in the validation object; do not fabricate values. Include a methods/coverage object and explicitly distinguish successful records from bounded failures. The stopping condition is the four-record completion rule above; do not extend the system set without identifying the extension as out of scope.
