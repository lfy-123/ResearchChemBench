# Scientific objective

Using the public 1f + ethynylbenzene system, independently test the authors' qualitative proposal that visible-light reaction proceeds through a photoaccessible triplet, stepwise cycloaddition manifold with two competing [4+2] and [2+2] closures. Determine which channel is kinetically preferred by calculating channel-specific activation free energies from a clearly identified common reference state, and report the barrier difference with sign convention ΔΔG‡ = G‡([2+2]) − G‡([4+2]). The scientific object is the reaction-path network, not a product-yield simulation.

# Public inputs and scientific boundaries

The complete public chemical system is in `data/inputs/system.json`: neutral 3-(methylsulfonyl)-4-phenyl-1H-pyrrole-2,5-dione (maleimide_1f; explicit SMILES, formula, charge 0, singlet ground state) and neutral ethynylbenzene (ethynylbenzene_2a; explicit SMILES, formula, charge 0, singlet ground state), in acetonitrile at 298.15 K and overall charge 0. The channel definitions in that file are operational: channel_4plus2 forms a six-membered carbocycle fused to the original phenyl ring and can aromatize to a naphthalene-fused imide; channel_2plus2 forms the competing four-membered ring. You may generate conformers, complexes, excited/open-shell models, and transition-state guesses. Do not use the paper, SI, general web, or source-derived coordinates; do not treat any source intermediate/TS/product geometry as public input. Report the electronic-structure method, solvation, standard state, temperature, spin convention, and free-energy convention you actually use.

# Required scientific validation/investigation

Plan and execute a finite candidate search for both channel-defining pathways. Retain a stable identity for every candidate (reactant/reference, intermediate, TS, endpoint/channel, conformer and method). Deduplicate candidates by connectivity and a stated geometric/energetic criterion. Advance a candidate only when its intended connectivity and spin state are chemically interpretable. Validate minima with a frequency calculation (no chemically significant imaginary mode), TS candidates with exactly one intended imaginary mode plus IRC or equivalent endpoint/connectivity evidence, and open-shell candidates with spin contamination/stability diagnostics. Use one common reference or explicitly reconcile separate references before computing ΔΔG‡. Include at least one independent starting geometry or method sensitivity check for each winning channel when feasible. Completion requires either (a) both channels have a validated pathway-defining TS and comparable barriers, or (b) a scientifically justified bounded-failure report identifying the missing state and the search/validation limitation. Stop when that completion condition is met and no unvalidated candidate is being treated as decisive; otherwise stop after your stated conformer/guess/search coverage is exhausted and report the limitation. Do not claim global mechanistic uniqueness.

# Deliverables

Submit `report/results.json` conforming to `submission_schema.json`. It must contain the candidate/pathway ledger, validation evidence, reference-state definition, channel barriers when obtained, signed ΔΔG‡ when both are obtained, the preferred-channel conclusion, method/sensitivity information, and limitations. A bounded-failure branch is allowed only if it identifies the attempted coverage and missing validation. Include machine-readable artifact paths for logs, geometries, frequencies, IRCs, and spin diagnostics where available.
