# Scientific objective

Determine whether an independently constructed computational model supports the proposed origin of regioselectivity in Pd-catalyzed, directing-group-free C-H arylation of tert-butylbenzene with cyclohex-2-en-1-ol. Test the selectivity-determining C-H activation from the Int3-type palladium complex to the Int4-type palladacycle by locating and comparing the meta, para, and ortho transition-state pathways. The reproduction mode permits the qualitative author hypothesis that dual-ligand coordination and an amide-assisted, catalyst-organized C-H activation may control selectivity; it does not provide the winning pathway or any target value.

# Public inputs and scientific boundaries

The public input directory contains `system_definition.json` and `reactant_complex.xyz`. The system definition fixes the substrate as tert-butylbenzene (SMILES `CC(C)(C)c1ccccc1`), N-acetyl-L-phenylalanine, Pd(OAc)2, the Ag2CO3 silver oxidant used in the reported reaction system, the uniquely named auxiliary ligand L22 (2-(tert-butyl)-1,2,3,4-tetrahydrophenazine), HFIP, and cyclohex-2-en-1-ol (SMILES `CC1=CCCC(O)C1`), with neutral singlet component states. The XYZ file is the SI-labeled reactant-complex starting geometry in Angstrom; it is a coordinate seed, not a guarantee that every listed reagent is present in that snapshot. State explicitly whether Ag2CO3 is included, represented by a chemically justified active fragment, or treated as outside the selectivity model, and justify that choice from the stated boundary. Use the seed as a reproducible coordinate starting point and document any assembly, proton-transfer, ligand-binding, or conformational changes used to reach Int3 and each candidate TS. The measured quantities are (i) Gibbs free-energy barriers from the same Int3 reference to meta, para, and ortho C-H activation TSs in kcal/mol, (ii) the corresponding Int3-to-Int4 reaction free-energy change when obtained, and (iii) TS identity and connectivity. Do not score later reductive elimination or product energetics. The paper, SI, source PDFs, general web search, and unpublished target structures are not public inputs.

# Required scientific validation/investigation

Independently choose a defensible electronic-structure and thermochemical protocol, report it before interpreting results, and explain why it is appropriate for a Pd/Ag-containing dual-ligand model in HFIP. Generate at least one chemically distinct candidate for each meta, para, and ortho C-H activation pathway; retain candidate identity, atom mapping, reacting C-H bond, proton-acceptor atom, and starting geometry for every candidate. Deduplicate only after stating the structural criterion. Optimize the Int3-like minimum and each candidate TS, then advance only candidates that converge without an unreported constraint and whose connectivity matches the stated regioisomer.

For every advanced TS, perform a frequency calculation and require exactly one imaginary frequency whose displacement involves the intended C-H cleavage/metal-carbon bond-forming coordinate. Perform an IRC or an explicitly justified equivalent endpoint-following test in both directions and verify connection to the Int3-like reactant minimum and the Int4-like palladacycle; report failures rather than replacing them silently. Recheck energies on a consistent thermochemical convention, state standard-state and temperature choices, and keep all relative energies referenced to the same Int3 species. Completion requires either (a) validated meta, para, and ortho TSs with a complete barrier table, or (b) a bounded-failure report naming the missing regioisomer, failed validation, search coverage, and the next scientifically meaningful limitation. In the bounded-failure branch, set `completion_status` to `bounded_failure` and use `null` for unavailable barriers, ordering, and reaction free energy; do not insert placeholders or inferred values. Stop when all three regioisomeric channels have at least one validated TS or when additional candidate searches no longer produce a new converged stationary point after the agent's documented search strategy is exhausted.

# Deliverables

Submit `report/results.json` conforming to `submission_schema.json` and containing the protocol, candidate/validation records, barrier table, comparison, conclusion, limitations, and provenance paths. Include numeric barriers only for validated or explicitly marked failed candidates; never invent a value for a missing channel. Include enough atom labels or mapping notes for an evaluator to identify the reacting C-H bond and proton acceptor. Also submit any supporting input/output files needed to audit the reported calculations under `report/`.
