# Scientific objective

Test the authors' qualitative hypothesis that, in the base-mediated reaction of N-(p-tolylthio)phthalimide (2a) with N-hydroxy-3-oxo-N-phenylbutanamide (5a), the 1,3-dicarbonyl substrate can compete through a C-nucleophilic sulfur-transfer route as well as through its hydroxylamine O atom. Independently plan and execute calculations that identify the O-site and C-site transition states, compute their solution Gibbs barriers from one common reference ensemble, and use validated structures and interaction analysis to explain the observed chemoselectivity. Do not assume the authors' software, model chemistry, ordering, or numerical result.

# Public inputs and scientific boundaries

The complete public molecular identities, atom maps, charge, multiplicity, stoichiometry, base, solvent, temperature, and scope are in `data/inputs/system.json` and `data/inputs/structures.smi`. Atom 6 is transferred sulfur, atom 7 is the leaving-group nitrogen, atom 27 is the hydroxylamine oxygen, and atom 23 is the activated 1,3-dicarbonyl carbon. Compare exactly two initial substitution events: O-site means form 27–6 while cleaving 6–7; C-site means form 23–6 while cleaving 6–7. Use one common balanced reference ensemble containing one 2a, one 5a, and at least one sodium counterion; report any added explicit solvent/base or alternate ion pairing. The primary physical boundary is a closed-shell singlet solution model in DME at 213.15 K; later cyclization, rearrangement, product formation, yields, and full cascade kinetics are outside scope.

# Required scientific validation/investigation

Generate and deduplicate candidate ion-pair, tautomer, conformer, and transition-state structures for both named channels. Advance only candidates whose atom-map connectivity matches the specified bond changes. Validate each retained minimum by frequency analysis and each retained transition state by one imaginary mode whose displacement involves the specified forming/breaking bonds, plus an IRC or an equivalently documented two-endpoint path check. Use a consistent free-energy convention and reference for both barriers, and report method, solvation, thermal treatment, candidate provenance, rejected candidates, and sensitivity checks. Completion requires at least one independently validated candidate for each channel or a scientifically justified bounded failure for a named channel. Stop when both channels have been searched across the declared starting ensemble set and additional starts no longer produce a distinct validated candidate under the stated deduplication rule; if that condition cannot be met, report coverage and the limitation rather than inventing a result.

# Deliverables

Submit `report/results.json` conforming to the schema. It must include search/validation records for both channels, the selected candidate identities and barriers when available, the channel ordering and difference when both are available, structural/interactions analysis, and explicit bounded-failure and limitation fields. A successful conclusion must be supported by the submitted candidate-level validation evidence; a bounded failure must name the missing channel and the search actually attempted.
