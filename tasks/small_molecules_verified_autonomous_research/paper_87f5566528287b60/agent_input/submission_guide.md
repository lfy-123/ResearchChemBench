# Submission guide

Submit `report/results.json`, `report/report.md` and actual inputs, outputs, logs and analysis code under `research/`, following `submission_schema.json`.

Use stable IDs for hypotheses, investigations, evidence and conclusions. Every evidence/investigation link and conclusion/evidence link must resolve. List each referenced native artifact in `reproducibility.artifact_index` with a safe relative path. Preserve molecular identity, site mapping, state, units, conditions and quantity definitions. Use null with an explanation when a quantity is unavailable.

Record actual methods and outcomes without private chain of thought. No fixed hypothesis, conformer, tool or job count is required. Failed calculations must be identified with their real logs.

Evidence and appropriate validation are prerequisites for each claim. An established physically equivalent explanation may answer the question. Schema validation does not certify scientific correctness.

## Resource protocol

Use public molecular inputs, available computational tools and traceable molecular-property resources. Document independently sourced catalyst properties and their physical definitions alongside your own substrate calculations.
