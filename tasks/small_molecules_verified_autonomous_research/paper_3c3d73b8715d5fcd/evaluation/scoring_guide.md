# 独立结论拆分评分（2026-11-03 采用）

本次采用的拆分方案：保持100分与原科学问题范围；已验证的独立局部结论与整体连通性/竞争结论分别计分，不给尝试次数、耗时、结构搭建、负频数量或承认局限计分。单独局部项不能被未绑定的全局能量清单阻断，也不能反过来视为整体机制已经完成。各项只按pass/fail给固定权重；无need_review。报告中与题定结论相反的最终答案仍须在对应最终结论项失败，不能掩盖。
必要数值仍必须来自真实计算；可在报告、results.json及其明确引用的原生结果中核验。对已经明确给出的同参照两数，允许直接相减或单位换算，不因缺少重复抄写的差值/特定JSON键名而失败；不得补做计算、猜测缺失数据或替模型发明未提出的科学解释。

- p1_local_hydrogen_mechanism（15分）：以真实反应模式、IRC或等效两端连接证据说明相关金属中间体经β-H消除与氢递送等局部转化形成P1相容的键和氢分布。可靠替代机制可接受。必须明确局部前体、两步连接及Rh/CO库存，不要求该局部片段已经接通底物入口或游离产物释放；未接通时只能声称局部机制。不能只凭负频或产物图通过。 必要证据：局部转化的实际活化自由能、各步前体定义和对应成键/氢迁移证据；不能相加局部势垒冒充整体势垒。

- p1_connected_formation（15分）：实际相连证据把底物活化入口与P1局部出口接通，形成成键、氢、配位及CO库存自洽的产物形成解释。片段分别存在但未接通不通过。不强制完整再生/产物重入网络或作者固定节点。 必要证据：关键中间体相对能量、对应局部活化量及配位/CO换参照关系。

- p2_local_cis_closure（15分）：真实反应模式和IRC或等效连接证据支持相关金属中间体经闭环形成cis-P2相容的骨架与相对构型，明确催化剂参与。仅优化题给P2不能通过。可对结合态产物作有界结论，不以未完成入口、产物释放或P1路线为本项否决理由。 必要证据：局部闭环实际活化自由能及前体、成键和cis构型映射的原生证据。

- p2_connected_formation（15分）：实际连接证据把烯烃/联烯入口与cis闭环接通，说明净[2+2]成键及催化剂作用。CO2入口不能无证据拼接CO1出口；需有配体交换和库存对应。 必要证据：相连中间体相对能量、局部活化量与CO/配位参照换算。

- activation_control（10分）：结合实际反应能量与催化剂配位/CO 账本，识别控制所研究路线活化需求的化学转化，并说明局部前体与稳定催化态参照的区别。参考模型中初始 endo 氧化环金属化构成通往 P1 的主要需求；有证据的等效静息态/路线解释可以通过。仅罗列若干 TS 数值或把单个全局高度当局部势垒失败；不要求作者总体或局部势垒数值。 必要证据：通往 P1 的关键相连反应态/中间体相对能量与局部活化量，包含模型内的 CO/配体库存。；通往 P2 的关键相连反应态/中间体相对能量与局部活化量，包含模型内的 CO/配体库存。；从局部前体及稳定催化态出发的活化量、两分支可比总体活化需求及差值；交代换参照关系。

- product_branch_competition（20分）：用实际、配平且可比的分支证据支持 P1/P2 两种形成路径均具有竞争可达性的结论，并解释协调环境如何关联该竞争。不是重复两张产物图或“观察到两个产物”；不能因某一局部势垒较低就未经参照处理断言另一支不可能。不规定势垒差窗口、产率或固定分支拓扑。 必要证据：通往 P1 的关键相连反应态/中间体相对能量与局部活化量，包含模型内的 CO/配体库存。；通往 P2 的关键相连反应态/中间体相对能量与局部活化量，包含模型内的 CO/配体库存。；从局部前体及稳定催化态出发的活化量、两分支可比总体活化需求及差值；交代换参照关系。

- initial_mechanism_preference（10分）：对相关初始转化作实际比较，解释优选机制及配位/配体交换假设。参考支持 endo 氧化环金属化优于 exo 或先 C–H 活化/直接亲核进攻的相关方案；不要求所有文献方案全算，只须比较能支撑主张的实质竞争者。证据充分的等效初始机理可接受。只提出一条能运行的路径而不比较，不能回答本项。 必要证据：所选初始机制与实质竞争机制的可比活化量及差值，不要求穷尽论文所有方案。
