H. Computational Experiments

All calculations were conducted using DFT implemented in the Gaussian 09 suite of ab initio
quantum chemistry programs with Becke’s three-parameter exchange functional B3LYP
including Grimme’s D3 dispersion correction. Geometry optimizations were conducted using
Pople’s 6-31G(d,p) basis set for the main group elements. The energies of the optimized
structures were reevaluated by additional single point calculations on each optimized geometry
using the same functional and Pople’s 6-311++G(d,p) basis set. Solvation effects were adopted
at the self-consistent reaction field polarizable continuum model (IEF-PCM) with the dielectric
constant of 32.63 for methanol.
