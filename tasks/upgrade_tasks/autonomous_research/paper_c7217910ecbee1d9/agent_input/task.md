# Scientific objective

Determine how zero, one and two intact B(C6F5)3 ligands change electron attachment to the complete PAl12 core. Distinguish ligand/core localization and structural relaxation by matched neutral/anion, vertical and frozen-core controls; test whether an intact-core interpretation survives the actual endpoint and density evidence.

# Public inputs and scientific boundaries

Use `system_specification.json`: n0=PAl12 (13 atoms), n1=PAl12BC18F15 (47 atoms), n2=PAl12B2C36F30 (81 atoms), each at charge 0 and −1. Atoms 1–13 are the common P/Al core; ligand A uses 14–47 and B uses 48–81, with explicit covalent bonds. Neutral systems have odd electron count and even multiplicity; anions have even count and odd multiplicity. Preserve intact ligand graphs and test the complete core after every relaxation. No truncated ligand, solvent, counterion, graphene or periodic surrogate is allowed. A graph-defined initial core is not a demonstrated minimum. Full shell-orbital proof and additional ligand families are optional.

# Required scientific validation/investigation

Use the staged pilot gate in `controls.json`: obtain the original intact n2 neutral/anion DFT minimum pair before expanding the full control matrix; n0/n1 are preparatory diagnostics only. For each n, explore plausible spin/site/orientation classes, optimize neutral and anion independently, validate stationary points and compare all retained candidates under a common electronic-structure convention. At each neutral minimum calculate vertical anion energy/density; separate electronic VEA, electronic AEA, ZPE-corrected AEA and anion relaxation. Freeze atoms 1–13 at a single validated neutral n0 core for the matched constrained series, relaxing only ligands; compute electronic attachment differences without borrowed thermal corrections. Analyze same-grid added-electron density and a consistent core/ligand population partition. Compare n1−n0 and n2−n1 for free, vertical and frozen-core results, and quantify basis/diffuse or state sensitivity for a decisive pair. Real, thoroughly evidenced reconstruction may exclude a candidate or invalidate an intact-model comparison; report null AEA for excluded objects, preserve coverage and do not rename an unrelated aggregate. Failure to converge once is not evidence of nonexistence. Fixed-core controls and charge analysis can bound competing explanations but cannot uniquely prove an exclusively electrostatic mechanism.

Test at least two distinguishable explanations with the required numerical comparisons. Support, refutation and evidence-sufficient indistinguishability are equally acceptable; missing core controls are incomplete. Quantify one decisive sensitivity using both baseline and perturbed results. Optional extensions are not scored requirements.
