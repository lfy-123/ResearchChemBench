# Version 2 route record (private metadata)

The source studies M3 in PM6/BTP-eC9 films and includes finite molecular interaction models. The defensible executable subproblem is the local molecular interaction account for these source components, not a prediction of film/device performance.

The authors propose planar M3 with an N···S conformational lock and quadrupolar electrostatics, and compare local association with PM6 BDT/BDD units and BTP-eC9 core/end regions (main Fig1, pp2–4). They report B3LYP/6-31G geometry optimizations; main p7 mentions Gaussian09 while p8 §4.4 says Gaussian03, so retain this source discrepancy. Their printed Qzz uses D, which lacks the length dimension required for a quadrupole; reproduce only with an explicit physical convention. Exact reproducible pair input geometries and complete interaction protocol are not supplied in these source materials. Earlier benchmark cut/cap graphs are builder-defined transcriptions, not author-optimized reference structures. Document limitations of any reconstruction or justified substitution.
