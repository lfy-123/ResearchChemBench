# 螺烯静态HRS：V1真实计算与科学审查

结论：本次四成员源方法基线不支持“π扩展必然增强HRS”，也不支持5/7差异完全由五个内缘扭角造成。1→3的HRS增加，而5→7降低；把5/7五个对应扭角统一为+20°后，7＜5仍成立，差距反而扩大。这个结论限于本任务的气相、中性单重态和指定电子结构方法，不能推广为所有螺烯或材料的规律。

## 科学问题与作者路线

原文及SI提供B3LYP/6-31G(d)几何/频率、CAM-B3LYP/6-31+G(d)静态响应路线和HRS/去偏振定义。采用该基线比较1、3、5、7；五个对应扭角的受限控制及解析/有限场校准是升级任务新增检查，不冒充作者原有计算。静态ω=0与4556nm动态响应严格分开。

βHRS=√(〈βZZZ²〉+〈βXZZ²〉)，DR=〈βZZZ²〉/〈βXZZ²〉；采用完整27分量、静态置换对称和1 au=8.6393×10⁻³³ esu。没有把单个Cartesian分量当HRS。原生档案与打印张量相互核对，8/16/32方向积分阶数及刚体旋转一致，并补独立解析球面矩公式核查。

四个松弛结构均完成全显式氢元素/连接图、电荷、多重度、源方法检查；原生四项Tight收敛均YES，完整3N−6振动频率为正。Compound5为明确复用的历史完整极小值，其余为本轮计算。旧能量不因PASS标签自动复用。
