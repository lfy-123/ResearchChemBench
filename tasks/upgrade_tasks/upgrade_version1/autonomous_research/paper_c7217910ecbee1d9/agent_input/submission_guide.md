# Submission guide

Development status: EXPANDED REFERENCE PENDING; no calibrated expanded reference or publishable upgraded score.

`results.series` has exact n0/n1/n2 entries. A `retained_pair` supplies two validated free minima, vertical anion, separate energy/ZPE quantities, fixed-core pair and density/population data. `comparisons` requires n1−n0 and n2−n1 with signed numerical differences. A complete submission requires retained n0/n1/n2 pairs and closure of the original n2 pilot. In a partial submission, a rigorously evidenced excluded n2 member may use `evidenced_exclusion`, with converged outside-identity structures, minimum/coverage evidence and null AEA; dependent comparisons must state exclusion and null differences. This records a scoped scientific falsification, never a substituted reconstructed-cluster AEA. Mere failures use partial/bounded_failure. Evidence-supported collapse of individual starting candidates is allowed when the retained endpoint coverage is complete. If the original intact n2 endpoints are absent, status remains partial/bounded_failure; missing whole panels cannot be excused as indistinguishability.

The top-level `status` is `complete`, `partial` or `bounded_failure`. Complete requires closed prerequisite records backed by actual evidence, methods, all results panels, at least two hypothesis records and a quantitative sensitivity record. This hypothetical complete contract does not certify that the current development package is scientifically validated. Failed/partial submissions require `failure_report` and an incomplete conclusion; zero engine launches is truthful when failure precedes computation. Never enter zero for an unknown scientific value.

Each job ID and comparison reference must resolve uniquely. Every referenced artifact must exist, match its hash, and contain the named raw calculation; a schema-valid path or synthetic test fixture is not evidence. Hash the exact input, coordinate, log, wavefunction/density and analysis files used. Keep units, atom labels, charge/spin and geometry reference explicit. The report must explain numerical derivations and why the control can falsify the proposed explanation.

Optional work must be labelled separately. No extra ligand family, Group B junction, SAPT decomposition, docking, graphene or bulk/application inference is required unless explicitly in the core task.
