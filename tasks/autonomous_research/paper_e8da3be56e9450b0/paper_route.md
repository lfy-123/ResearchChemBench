# Private paper route (evaluator-only)

The source paper tests a neutral 2×2×2 periodic BaTiO3 model with Zn2+ on a Ba site and Co4+ on a Ti site, using independent relaxation and Berry-phase polarization against an undoped control. The authors' qualitative interpretation is that dopant-induced structural distortion and local Zn–O/Co–O hybridization can enhance ferroelectric response. This file is retained only as the private workflow record; paper software, ordered protocol, numerical results, result structures, ordering, and tolerances are not public task inputs.
