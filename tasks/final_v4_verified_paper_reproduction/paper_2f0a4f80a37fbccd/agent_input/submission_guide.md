# Submission and evidence

Submit `report/results.json` using `submission_schema.json` and a readable `report/report.md`. Answer every final question in the task, identify the actual systems and electronic states, and define units, environments and energy/geometry/spectral references. Keep supplied observations, source baseline and newly computed results distinct.

Link each claimed result to genuine calculation or reproducible analysis records and workspace-relative `outputs/`, `data/` or `code/` artifacts with SHA256 and precise locators. Preserve native inputs and outputs; derived values must be recoverable from them. Source values and normal termination alone do not establish a scientific result. Validate minima, transition states, connections, response states or statistical claims only as required by the proposition being asserted. A local model supports conclusions within its demonstrated scope.

Scoring uses `paper_science_v3` / `final_results_100`: independent final scientific propositions total 100 points. There are no process points or score multiplier. Supported equivalent interpretations pass; unresolved substantive scientific conflicts fail the affected item. Missing or scientifically invalid evidence fails the affected proposition; author-value matching windows do not apply. A general statement of uncertainty does not replace an answer. Research logs may be empty and do not control scientific credit.

Use the schema status that accurately describes the submission and list missing work. Schema acceptance is a format check, not a declaration of scientific success. No fixed software, calculation count, hypothesis count or search order is prescribed. Use the tools and resources actually exposed by the runner. The supplied observations are visible from the outset and are not a hidden prediction set.

Reproduce the disclosed author baseline or justify a scientifically comparable substitution and its consequences. This qualifies the final results; protocol completion and copying disclosed targets earn no independent points.
