# Stage02 可构建计算流程改造与 200 篇评估报告

## 结论

Stage02 的硬门控目标已经从“计算是否主导论文”调整为“论文是否包含作者实际执行、完整、非平凡，
并可独立形成有科学意义评估子任务的计算化学流程”。纯计算、计算主导混合、计算与实验共同主导，
以及实验主导但包含完整计算子任务的论文均可进入 Stage03；实验数据拟合、晶体学 refinement、单一
轨道图和简单公式估算不通过。

在冻结的 200 篇高难度分层评估集上，按原始独立标签计算，Pass/Reject 精确率为 90.1%，召回率
为 99.3%，F1 为 94.4%。两名独立复核者只依据论文正文和全部 SI 复核争议样本，并且只在两人结论
一致时修正参考标签。修正 5 个标签后的精确率为 91.4%，召回率为 98.6%，F1 为 94.8%。

该结果支持把 Stage02 用作高召回的计算流程入口，但不支持用细粒度论文角色做硬淘汰。七分类精确
匹配率为 73.0%，计算主导、共同主导和实验主导之间仍有明显混淆；这些角色应保留为审计元数据，
所有四种 Pass 均交给 Stage03 检查软件、资源和工具箱覆盖。

## 最终决策空间

| 决策 | 含义 | Stage02 行为 |
|---|---|---|
| `computational_content_confirmed` | 纯计算研究 | Pass |
| `computational_primary_mixed_confirmed` | 计算主导、实验验证或辅助 | Pass |
| `computational_experimental_co_primary_confirmed` | 计算与实验共同主导 | Pass |
| `experimental_primary_benchmarkable_computation` | 实验主导，但存在完整、非平凡的计算子任务 | Pass |
| `computational_workflow_not_benchmarkable` | 有计算痕迹，但不能形成有意义的输入—计算—输出链 | Reject |
| `computational_content_not_found` | 没有作者实际执行的计算化学流程 | Reject |
| `uncertain` | 证据不足 | Hold |

`non_original_article` 与 `processing_failed` 继续作为文章类型和运行状态记录，不混入语义标签。

## 实现流程

1. 读取 Stage01 产生的正文和全部已知 SI 结构化文本。
2. 本地规则宽召回计算信号、作者实验信号和论文叙事，不用规则判断论文主次。
3. 全文没有实质计算信号的论文零调用淘汰；非原创论文直接记录状态。
4. 第一次 Qwen 调用抽取计算工作流并给出论文角色、因果方向和证据 ID。
5. 第二次独立 Qwen 调用只读取原始证据包，不读取第一次答案，逐项判断：
   - 是否有可识别的化学模型或体系；
   - 是否执行了真实计算或模拟；
   - 是否生成独立化学输出；
   - 输出是否用于科学结论；
   - 工作流是否非平凡；
   - 是否只是实验数据处理。
6. 第二次调用控制 Pass/Reject，第一次调用提供论文角色。作者实验轴不确定时，不否定已经完整确认
   的计算流程。
7. 程序验证 evidence ID 和置信度，写入统一 registry；Stage00–03 明确拒绝时才删除论文资产，Hold
   保留以便恢复。

Stage02 对实验主导论文的通过不代表论文已经适合作为 benchmark。Stage03 继续检查核心软件、工具箱
原生调用范围和资源，Stage04 进行 MinerU 高质量解析，Stage05 再判断能否构造完整、可评分任务。

## Prompt 边界

正例包括有明确体系、方法、生成结果和科学用途的 DFT、MD、自由能、反应路径、电子结构、谱学模拟、
微观动力学等流程。纯模拟论文不需要外部实验验证或现成 ground truth 才能通过 Stage02。

以下内容单独出现时明确不通过：测量谱图或瞬态曲线拟合、仪器标定和数值换算、把测量值代入标准
公式、测量信号的统计/机器学习分类、Rietveld 或 PDF refinement、生命周期/流程模型、
AlphaFold-only、背景软件引用、单一 HOMO/LUMO 图或孤立数值。

## 评估集

- 样本数：200。
- 来源：冻结的历史完整解析结果，包含正文和全部已知 SI 路径及 SHA256。
- 抽样性质：有意覆盖旧流程的困难和边界样本，不代表远端语料中的自然通过率。
- 参考标签：由 GPT-5.6-sol 子智能体逐篇阅读来源文本生成，Stage02 推理与标注相互隔离。
- 推理模型：共享 worker 上的 `Qwen3-30B-A3B-Instruct-2507`。
- 推理结果：200/200 完成，0 个运行失败；195 篇各调用 2 次，共 390 次语义调用；2 篇零调用
  淘汰，3 篇识别为非原创文章。
- 外部 worker 按用户要求保持运行，本次没有释放。

最终预测为：纯计算 12，计算主导混合 2，共同主导 25，实验主导但计算可构建 112，计算流程不足
1，无计算内容 45，非原创 3；总 Pass 为 151。

## 误差分析

裁决后剩余 13 个 FP 中，10 个是明确模型误判，集中在实验数据处理或过于简单的计算：曲线/谱学
拟合、晶体结构 refinement、简单公式估算、单一轨道图和 AlphaFold 加低信息 docking。`0005`、
`0020`、`0110` 的两名独立复核者结论不一致，属于当前定义下的真实边界项，暂时保留原始标签，
不通过主观改标提高指标。

两个明确 FN 为：`0006` 的分子建模/docking 流程，以及 `0133` 在 SI 中给出的 Gaussian16 结构
优化、频率和 Raman 计算。它们说明有界证据包仍可能没有把关键 SI 方法与生成结果同时交给复核模型。

当前最重要的剩余改进不是再收紧论文主次，而是提高证据包对“方法—体系—输出”跨段关联的覆盖，
并继续用独立小规模标注集校准实验数据处理边界。为控制成本，本版本不增加第三次模型调用，也没有
为个别 DOI、软件或论文添加专用规则。

但因此不能把当前 200 篇集合视为严格双盲的最终测试集。后续正式验收应另建从未用于 prompt 调整的
holdout。
