## 2. 代码修改

### 2.1 Converter 可写 scaffold

- `_setup_converter_inputs()` 除了生成只读 input packet，还把
  `paper_reproduction/` 的**内容**复制到 `outputs/autonomous_research/`。
- 每次 recovery artifact 合并后运行一个 transport-only scaffold 修复：
  - 只从 authoritative reproduction public tree 补齐缺失的顶层任务文件；
  - 若存在确定错误的 `autonomous_research/paper_reproduction/` wrapper，先把缺失文件提升到根，再移除
    wrapper；
  - 不改写科学问题、方法、Ground Truth、答案或 disclosure 语义。
- converter semantic validator 增加嵌套 wrapper/private packet 检查。

### 2.2 Codex feature 配置

- 给 Codex harness 增加可配置 `codex_disable_code_mode`；Stage06/07 默认启用该配置。
- 命令行显式加入 `--disable code_mode --disable code_mode_host`，避免不存在的 host 作为错误事件进入
  Agent 轨迹；shell/unified exec 保持可用。

## 3. Prompt 修改

- Stage06B 明确：可写 output tree 已在正确根目录预置；直接编辑，禁止复制整个
  `inputs/task_pair/` 或创建 `paper_reproduction/` 子目录。
- Recovery Prompt 明确优先编辑预置顶层，不自行 bootstrap/展平。

  “most central among closed candidates” 不等于“core”；若它仍仅提供 supporting-only evidence，
  不能替代 unclosed direct workflow。
